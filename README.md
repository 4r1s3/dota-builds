# Dota Builds

Быстрые актуальные билды по про-матчам: прокачка, таланты, старт, кор- и ситуативные предметы по позициям, плюс последние игры про-игроков с пометкой «игра шла очень хорошо» и подсветкой нестандартных предметов.

- Данные: OpenDota (про-матчи текущего патча, до 30 дней).
- Обновление: GitHub Actions раз в день (`.github/workflows/update.yml`), сайт на GitHub Pages.
- Локально: `python scripts/build.py && python -m http.server -d site 8000`.

Горячие клавиши: `/` — поиск, `Enter` — открыть первого героя, `Esc` — назад к списку.
